# Industrial Telemetry Schema

This document defines the canonical schema for simulated telemetry generated by the AquaRisk AI Time-Series Simulator.

## Core Telemetry Fields

| Field | Type | Description |
|-------|------|-------------|
| `timestamp` | datetime | ISO 8601 timestamp of the reading (e.g. 5-minute intervals) |
| `plant_id` | string | Unique identifier for the plant |
| `zone_id` | string | Identifier for the zone within the plant |
| `line_id` | string | Identifier for the production line |
| `machine_id` | string | Identifier for the machine/asset |
| `sensor_id` | string | Unique identifier for the sensor |

## Readings
| Field | Type | Unit | Description |
|-------|------|------|-------------|
| `pressure_bar` | float | Bar | Water pressure at the sensor node |
| `flow_lph` | float | L/h | Volumetric flow rate |
| `temperature_c` | float | °C | Fluid temperature |
| `vibration` | float | mm/s | Machine vibration level |
| `rpm` | float | RPM | Machine rotational speed |

## Context & Production
| Field | Type | Description |
|-------|------|-------------|
| `production_level` | float | Current production capacity percentage (0.0 to 1.0) |
| `machine_status` | string | Status of the machine (`ACTIVE`, `IDLE`, `MAINTENANCE`) |
| `shift` | string | Current operating shift (`SHIFT_1`, `SHIFT_2`, `SHIFT_3`) |
| `operating_hours` | int | Cumulative operating hours for the machine |

## Analytics & Deviations (Derived)
| Field | Type | Description |
|-------|------|-------------|
| `expected_flow_lph` | float | Expected baseline flow for the current production_level |
| `actual_flow_lph` | float | Actual flow (with noise + leak logic) |
| `flow_deviation_pct` | float | Percentage difference between actual and expected flow |
| `pressure_deviation_pct`| float | Percentage difference between actual and expected pressure |
| `rolling_flow_mean` | float | Rolling mean of flow over previous N intervals |
| `rolling_pressure_mean`| float | Rolling mean of pressure over previous N intervals |

## Diagnostics & Labels
| Field | Type | Description |
|-------|------|-------------|
| `sensor_health` | string | Health state of the sensor (`OK`, `FAULTY`, `DRIFTING`, `STUCK`) |
| `data_quality` | string | Data quality flag (`GOOD`, `MISSING`, `NOISY`) |
| `event_type` | string | Scenario injected (e.g., `NORMAL_OPERATION`, `GRADUAL_LEAK`, `SENSOR_FAULT`) |
| `event_id` | string | Unique ID for the active incident (Null if normal) |
| `leakage_status` | int | Binary label (0: No Leak, 1: Leak). Use for binary classification tasks. |
| `severity` | string | Severity of the leak/event (`LOW`, `MEDIUM`, `HIGH`, `CRITICAL`) |
