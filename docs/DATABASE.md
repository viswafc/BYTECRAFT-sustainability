# Database Schema Documentation

AquaRisk AI uses PostgreSQL (with SQLite support for local rapid development).

## Entities and Relationships

### 1. Plant
The top-level industrial facility.
- Contains many `Zones`

### 2. Zone
A distinct physical or operational area within a Plant.
- Belongs to `Plant`
- Contains many `Lines`

### 3. Line
A specific production or process line within a Zone.
- Belongs to `Zone`
- Contains many `Machines`

### 4. Machine
A piece of industrial equipment (e.g. Pump, Valve) located on a Line.
- Belongs to `Line`
- Contains many `Sensors`

### 5. Sensor
A specific telemetry capturing device attached to a Machine.
- Belongs to `Machine`
- Types include: pressure, flow, vibration
- Records many `SensorReadings`

### 6. SensorReading
Time-series telemetry value generated by a Sensor.
- Belongs to `Sensor`
- Heavily indexed on `timestamp` and `sensor_id`

### 7. Incident
Anomalies or verified events (e.g., leaks) associated with a Plant.
- Belongs to `Plant`

### 8. ModelRegistry
Tracks the versions and metrics of Scikit-learn/ML models used in the system.

## Initialization
To generate the base hierarchy:
```bash
python database/seeds/seed.py
```
